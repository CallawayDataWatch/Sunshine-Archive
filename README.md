# Sunshine Archive

Public archive of Data Center specific Sunshine Law requests and responses for Missouri, maintained by Callaway Data Watch (CDW).

## What this is

CDW files public records requests under Missouri's Sunshine Law to track local government decisions, spending, and communications around data center development across Missouri. This repository holds the documents we receive, along with a searchable interface so community members can look through them without needing any technical background.

## How to use it

Visit the live site: [link will go here once Pages is enabled]

Type a keyword into the search box to find documents. You can also filter by agency or topic. Click any result to open the original PDF.

## What's in the repository

- `docs/documents/` — the PDF records themselves
- `docs/text/` — extracted text used for search
- `docs/data/` — metadata describing each document (date, agency, topic, status)
- `docs/index.html`, `docs/style.css`, `docs/search.js` — the search site

## About Callaway DataWatch

Callaway Data Watch is a grassroots community transparency and accountability organization in Callaway County, Missouri, working in conjunction with the statewide data center coalition NMDDC.
